# Executive report assets

Local, offline report assets, sourced September 20, 2026 from the reviewed website at commit `8f8486e`:

- `inter.woff2`: `public/assets/home/reviewed-0.woff2`, the Reviewed Inter face used by the current homepage.
- `merchjar-logo.webp`: `public/assets/brand/merchjar-logo.webp`, the actual wordmark.
- `report.css`: compact report adaptation of the homepage's cream/paper/ink tokens, white result board, metric hierarchy and lime analysis ground. Cobalt/coral distinguish the query groups.

The renderer embeds the binary assets in its HTML. It does not contact font servers, load remote scripts or send analytics. Source-derived customer files are never bundled here. Inter is distributed under the included SIL Open Font License; Merch Jar assets are covered by this skill's LICENSE.
