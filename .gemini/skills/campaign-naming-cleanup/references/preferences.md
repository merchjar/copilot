# Shared campaign naming preferences

Read [Merch Jar Connect's shared contract](../../merchjar-connect/references/campaign-naming.md). Use its `scripts/campaign_naming.py` for inspect, resolve, save and render. Connect 1.4 or later is required for this integration. If the shared helper is missing, report the version gap and preserve existing settings.

Save the approved convention beside the active private configuration. Keep durable per-profile rename receipts and stable per-campaign exceptions in `campaign-naming-records/` beside that file. Saving the default and approving live renames are separate user choices.
